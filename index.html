Overview

프로젝트 개요

AI 기반 스마트 터널 관제 시스템은 터널 CCTV 영상을 활용하여 차량 객체탐지, 차량 추적, ROI 자동설정, 차선추정, 교통상태 분석, 사고탐지, 센서리스 환기 대응을 통합 수행하는 실시간 관제 시스템입니다. 기존 터널 관제 환경에서 운영자의 육안 모니터링에 의존하던 교통 흐름 판단과 위험상황 감지를 AI 기반으로 자동화하는 것을 목표로 개발했습니다.

영상 기반 관제 자동화

별도 도로 센서 없이 CCTV 영상 분석만으로 차량 흐름과 위험 징후를 판단하도록 설계했습니다.

실시간 대시보드 연동

Flask API와 React 대시보드를 연결해 영상, 상태, 이벤트, 환기 정보를 관제 화면에 제공합니다.

오탐 방어 중심 설계

혼잡, 가림, 원거리 소형 객체처럼 사고로 오인되기 쉬운 상황을 후처리 로직으로 방어했습니다.

Problem

문제 정의

터널은 폐쇄적인 구조로 인해 사고 발생 시 대응 시간이 늦어질수록 2차 사고와 인명 피해로 이어질 가능성이 높습니다. 그러나 기존 관제 방식은 다수의 CCTV 화면을 운영자가 직접 확인해야 하므로, 혼잡·정체·사고 징후를 실시간으로 일관되게 판단하기 어렵다는 한계가 있습니다. 본 프로젝트는 별도 도로 센서 없이 CCTV 영상만으로 차량 흐름과 위험 상황을 분석하여, 관제사의 판단을 보조하는 AI 기반 스마트 터널 시스템을 구현하는 데 초점을 두었습니다.

다중 CCTV 관제 부담

관제자가 여러 화면을 동시에 확인해야 하므로 위험상황 인지 시점이 늦어질 수 있습니다.

상황 판단의 일관성 부족

혼잡, 정체, 일시 정지 같은 상태를 사람마다 다르게 판단할 수 있어 자동화 기준이 필요했습니다.

센서 의존 구조의 한계

추가 센서 설치 없이 기존 CCTV 인프라만으로 교통 분석과 환기 대응 정보를 제공하는 방향을 택했습니다.

Architecture

시스템 아키텍처

React 기반 프론트엔드와 Flask 기반 백엔드로 구성했으며, 백엔드는 CCTV 영상 스트림을 AI 분석 파이프라인으로 전달하고 분석 결과를 API 형태로 프론트엔드에 제공합니다. 프론트엔드는 실시간 영상, 교통상태, 차선 정보, 사고 이벤트, 환기 대응 정보를 대시보드 형태로 시각화합니다.

CCTV 영상 입력 -> Flask Backend -> AI 분석 파이프라인 -> React Dashboard -> 관제자 모니터링

AI 분석 파이프라인

CCTV 입력 -> 차량 객체탐지 -> 차량 추적 -> ROI 자동설정 -> 차선추정 -> 교통상태 분석 -> 사고탐지 -> 웹 대시보드 출력
Features

핵심 기능

각 기능은 목적, 구현 방식, 결과가 연결되도록 설계했습니다.

객체탐지

목적터널 CCTV 영상에서 차량 객체를 실시간으로 인식
구현 방식YOLO11n 모델을 터널 차량 데이터에 맞게 학습하고, 실시간 처리 속도를 고려하여 경량 모델 적용
결과Precision 0.927, Recall 0.847, mAP50 0.913, 약 25 FPS 수준의 실시간 처리 성능 확보

ROI 자동설정

목적CCTV마다 다른 터널 구도에서도 분석 영역을 자동 산정
구현 방식초기 프레임의 차량 bbox 하단 좌표 분포를 기반으로 ROI를 자동 산정하고, 표본 부족 시 fallback 적용
결과ROI Match Rate 약 98%, ROI MAE 5px 이하 수준 달성

차선추정

목적동일 차선 내 차량 흐름을 분석하기 위한 기준 생성
구현 방식차량 위치 분포와 이동 궤적을 기반으로 대표 차선을 추정하고, 목표 차선 수 수동 지정 및 재추정 기능 적용
결과조건 충족 후 차선추정 성공률 100%

교통상태 분석

목적터널 내 교통 흐름을 정상/혼잡/정체로 분류
구현 방식단일 프레임 속도가 아니라 차량 이동량과 300프레임 평균 기반으로 상태 판단
결과화면 흔들림이나 일시적 가림에도 안정적인 상태 판단 가능

사고탐지

목적정지, 흐름 단절, 후방추돌 등 사고 패턴 감지
구현 방식사고 후보와 사고 확정을 분리하고, queue-only, small-far pair, bbox split false stop 등 오탐 방어 조건 적용
결과정상 및 혼잡 상황에서 오탐 방어 안정성 확보, 주요 사고 시나리오 탐지

센서리스 환기대응

목적별도 공기질 센서 없이 CCTV 기반 교통 흐름으로 환기 위험도 추정
구현 방식차량수, 평균속도, 체류시간, 밀집도를 기반으로 현재 및 5분 후 공기질 위험도 추정
결과교통상태와 연계한 환기 대응 지원 정보 제공

Retrospective

결과 및 회고

본 프로젝트를 통해 단순 객체탐지를 넘어, 영상 기반 차량 흐름 분석과 사고 위험 판단을 하나의 관제 시스템으로 통합하는 경험을 했습니다. 실제 CCTV 영상에서는 조명 변화, 차량 가림, 터널 구조, 혼잡 상황 등 다양한 변수가 발생하기 때문에 모델 성능뿐 아니라 후처리 로직, 상태 판단 기준, 오탐 방어 설계가 중요하다는 점을 확인했습니다. 향후에는 더 다양한 사고 유형 데이터를 확보하고, 사고탐지 로직을 학습 기반 모델과 결합하여 복합 사고 상황에서도 안정적으로 동작하도록 개선하고자 합니다.
