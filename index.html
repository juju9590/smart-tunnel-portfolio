프로젝트 핵심 요약

터널 CCTV 영상을 AI로 분석하여 교통흐름과 사고 가능성을 자동 판단하고, 웹 대시보드로 관제 정보를 제공하는 프로젝트입니다.

AI 영상 분석

YOLO11n 기반으로 터널 CCTV 영상에서 차량 객체를 탐지하고, 실시간 분석이 가능하도록 구성했습니다.

교통흐름 분석

차량 추적, ROI 자동설정, 차선추정을 활용하여 정상·혼잡·정체 상태를 판단했습니다.

사고탐지

정지 지속, 흐름 단절, 반복 사고 후보 패턴을 기반으로 사고 가능성을 탐지하고 오탐 방어 조건을 적용했습니다.

웹 대시보드

Flask 백엔드와 React 프론트엔드를 연동하여 실시간 관제 화면과 사고 이벤트를 시각화했습니다.

프로젝트 배경

터널은 폐쇄적인 도로 환경 특성상 사고 발생 시 2차 사고, 정체 확산, 공기질 악화 등의 위험이 빠르게 커질 수 있습니다. 기존 터널 관제는 CCTV 영상을 관제자가 직접 확인하는 방식에 의존하기 때문에, 여러 영상을 동시에 모니터링할 때 사고나 정체 상황을 즉시 발견하기 어렵다는 한계가 있습니다.

관제 부담

다수의 CCTV를 관제자가 직접 확인해야 하므로 위험상황을 놓칠 가능성이 있습니다.

사고 대응 지연

터널 사고는 빠른 초기 대응이 중요하지만, 수동 관제만으로는 즉각적인 판단이 어렵습니다.

AI 분석 필요성

CCTV 영상을 AI로 분석하여 교통흐름과 사고 가능성을 자동으로 감지할 필요가 있습니다.

시스템 아키텍처

본 시스템은 React 기반 프론트엔드와 Flask 기반 백엔드로 구성되며, 백엔드는 AI 분석 파이프라인과 연결되어 CCTV 영상을 처리합니다.

CCTV 영상 입력 → Flask Backend → AI 분석 파이프라인 → React Dashboard → 관제자 모니터링

AI 분석 파이프라인

CCTV 영상 입력부터 차량 객체탐지, 추적, ROI 자동설정, 차선추정, 교통상태 분석, 사고탐지, 웹 대시보드 출력까지 단계적으로 구성했습니다.

CCTV 입력 → 차량 객체탐지 → 차량 추적 → ROI 자동설정 → 차선추정 → 교통상태 분석 → 사고탐지 → 웹 대시보드 출력

핵심 분석 로직

CCTV 영상마다 다른 카메라 구도와 교통 흐름을 안정적으로 분석하기 위해 ROI 자동설정, 차선추정, 교통상태 판단, 사고탐지 로직을 단계적으로 설계했습니다.

ROI 자동설정

CCTV마다 터널 위치와 카메라 각도가 다르기 때문에 고정된 분석 영역 대신 초기 프레임의 차량 검출 분포를 수집해 ROI를 자동 설정했습니다. 최초 약 100프레임 동안 차량 위치를 누적하고, 실제 차량 분포 기준으로 ROI를 확정한 뒤 고정해 분석 범위가 흔들리지 않도록 구성했습니다.

초기 100프레임 bootstrap 차량 분포 기반 ROI 표본 부족 시 fallback 1회 확정 후 고정

차선추정

차량 추적 결과로 누적된 이동 궤적을 활용하여 대표 차선을 계산했습니다. 안정적으로 움직이는 차량의 궤적을 선형 흐름으로 분석하고, 1차 군집화로 흐름을 분해한 뒤 2차 군집화로 유사 흐름을 병합했습니다.

차량 궤적 기반 안정 차량 필터링 1차 군집화 2차 군집화 대표 차선 확정

차선 재추정 / 목표 차선 수

초기 차선추정 이후에도 CCTV 환경이나 차량 흐름에 따라 차선 기준이 달라질 수 있어 관제자가 차선 재추정을 요청할 수 있는 구조로 확장했습니다. 목표 차선 수를 수동 지정할 수 있게 하여 자동 추정 결과를 실제 도로 구조에 맞게 보정할 수 있도록 했습니다.

차선 재추정 목표 차선 수 수동 지정 운영자 보정 차선 메모리 활용 상태/사고 로직 연계

상태·사고 로직 연계

확정된 ROI와 차선 정보는 교통상태 판단과 사고탐지 로직의 기반 데이터로 활용됩니다. ROI는 분석 대상 차량을 제한하고, 차선 정보는 동일 차선 내 차량 흐름과 사고 후보 패턴을 판단하는 기준으로 사용했습니다.

ROI 기반 차량 필터링 동일 차선 흐름 분석 정상·혼잡·정체 판단 사고 후보 패턴 분석 오탐 방어 기반 정보

주요 기능 소개

단순 객체탐지에서 끝나지 않고, 차량 흐름 기반의 관제 기능을 통합적으로 구현했습니다.

Problem Solving

개발 과정에서 발생한 주요 문제를 로그와 시연 결과로 분석하고, 로직 개선을 통해 안정성을 높였습니다.

혼잡 상황에서 사고 오탐 발생

문제: 혼잡·정체 상황에서 차량이 겹쳐 보이거나 느리게 이동하면서 사고로 잘못 판단되는 문제가 발생했습니다.

해결: queue-only 방어, bbox 분리 오탐 방어, 소형·원거리 객체 방어 조건을 추가하여 정상·혼잡 상황의 오탐을 줄였습니다.

CCTV마다 다른 차선 위치

문제: 터널 CCTV마다 카메라 각도와 도로 위치가 달라 고정된 ROI와 차선 기준을 적용하기 어려웠습니다.

해결: 차량 검출 위치와 이동 궤적을 기반으로 ROI를 자동 설정하고, 대표 차선을 추정하는 방식으로 영상별 분석 안정성을 높였습니다.

순간 속도 변화로 인한 상태 흔들림

문제: 단일 프레임 기준 속도 변화만 사용하면 정상·혼잡·정체 판단이 흔들리는 문제가 있었습니다.

해결: 차량별 이동량 EMA와 일정 프레임 버퍼 평균을 함께 활용하여 교통상태 판단의 안정성을 개선했습니다.
